# Changelog

## [Unreleased]

### Added
- Status page management with real-time updates via Turbo Streams
- Incident lifecycle management (investigating, identified, monitoring, resolved)
- Subscriber email notifications with granular preference controls
- Synthetic monitoring (HTTP, HTTPS, TCP, Ping) with configurable intervals
- REST API with token authentication and rate limiting
- Webhook delivery with HMAC-SHA256 signatures and automatic retries
- MCP server endpoint for AI agent integration via ActionMCP
- Multi-tenant architecture with account-based isolation
- Magic link (passwordless) authentication
- Scheduled maintenance windows with subscriber notifications
- Docker and Docker Compose deployment support
- Kamal deployment configuration
- SSRF protection for webhook URLs
- SimpleCov test coverage tracking
